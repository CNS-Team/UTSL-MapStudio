# 生成模式与保护边界

## 连续母图

原生生成连续母图，再分为西、中、东。支持现有 11 种样式、特殊种子码、空岛基础环境补全和母图导入。默认每片 8400×2400、大师难度，总重叠 80 格 / 单侧 40 格。

种子合集支持 9 种原生特殊种子、37 项特性和 11 种组合配方。配方只调整本面板选项，不更换用户种子 / 难度 / 尺寸。更多雷击 / 无雷击、全境侵蚀 / 无侵蚀、更多陷阱 / 真正无陷阱等冲突会拒绝。极端组合不保证满足中心安全出生点 / 对象保护；工具应失败而不是写虚假 COMPLETE。

基础环境补全可能重新加入所选生态。需要特殊种子原貌时，应关闭补全。组件开关测试不代表所有种子组合均已完成真实世界生成。

## 独立标准三世界

分别生成三张正常标准尺寸世界，中间用输入种子，两侧由输入种子和方向确定性派生。西 / 中使用腐化，东使用猩红；实际种子和原生结果均留在批次记录中。

以中间世界实际海水顶面 Y 为基准，统一六处边缘物理水面和层元数据。外侧 80 格使用同一全深度自然剖面，80..219 列近海区域只校准相连海水的水面；不全图上下平移。x=220..width-220 内陆图格在设出生点前逐字段摘要保持不变。带外原生洞穴不保证完全一致。

接缝带的有界完整家具、标准宝箱及短矿车轨道可同 Y 整体移入 100..217 格保护区；只更新原宝箱坐标，保持物品 / 前缀 / 命名。过大结构、无法安全保护的对象、标牌 / 实体均拒绝，不静默删除。完整框架包围盒、物品和保存重读另核。

本模式用于正常原版地形。特殊种子、空岛 / 颠倒 / 天顶及额外补全请用连续母图。

## 出生点与结果

世界链为 1 西 — 2 中 — 3 东，中间是默认进入世界。天然中央地表浅水可建立固定中央 X、3 格宽、至多抬高 4 格的有支撑平台；不是回退洞穴 / 半空，不改接缝。只允许明确记账替换台内完整小装饰；跨框架对象、宝箱 / 标牌 / 实体、深水和危险液体仍拒绝。

每个成功批次包含三张 `.wld`、原生读图结果、接缝比较、配置片段、SHA 清单、`三联世界长图.png`、`长图说明.json` 和 `COMPLETE.json`。长图每像素取样 2×2 真实图格，去掉重复重叠区；不是客户端材质截图。`preview/三联世界总览.png` 是轻量预览。

仅使用包含 `COMPLETE.json` 的成功批次，输出目录必须为空。失败 / 取消批次保留以便诊断，但不得用于部署。

## 非承诺项

地图生成结果不等于 EdgeStitch 插件已安装，不等于游戏中传送 / 客户端渲染已验证，也不包含运行期挖掘、液体、宝箱的跨图同步或零延迟保证。本工具不会自动把新地图替换到生产服。
